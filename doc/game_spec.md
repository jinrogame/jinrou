# オリジナル人狼ゲーム 仕様書（確定版）

## 1. 概要・プレイ環境
* **ジャンル**：タスク（ミニゲーム）融合型・対面／オンライン人狼ゲーム
* **想定プラットフォーム**：スマートフォン向けWebアプリケーション（ブラウザ動作）
* **プレイスタイル**：各自のスマホを持ち寄り（または通話しながら）、リアルな会話とスマホ操作を組み合わせて進行
* **プレイ人数**：最大10人（例：10人プレイ時は人狼陣営3人・市民陣営7人を基本とし、ルームオーナーが自由に配分を設定可能）

---

## 2. ゲーム全体の進行フロー（ステップ1〜13）

### 【準備〜開始フェーズ】
1. **アプリ起動**
2. **プレイヤー名 ＆ 顔アイコン登録**：
   * ユーザーは自分の名前を入力する。
   * **スマートフォンのカメラ（インカメラ）を起動して自分の顔を撮影し、表示アイコンとして登録できる**（※写真選択やデフォルトアイコンも利用可能）。
   * 登録した顔アイコンは、ロビー・昼の生存者一覧・夜の追放投票・スキル選択画面など全画面でプレイヤーアイコンとして表示される。
3. **ルーム作成**：ルームオーナーが**最大ターン数（デフォルト：5ターン）**を指定してルームIDを発行する（※ロビー設定画面でも変更可能）。
4. **ルーム入室**：参加メンバーはルームIDを入力して入室する。
5. **役職配分・ターン数設定 ＆ ゲーム開始**：
   * ルームオーナーは全員の入室を確認し、**画面のインターフェース上で今回のゲームで使用する役職の内訳（配分）および最大ターン数（デフォルト5）を設定**する。
   * 設定完了後、ルームオーナーが「開始ボタン」をタップしてゲームを開始する。
6. **役職発表**：各プレイヤーの画面に自分の役職（および人狼同士・恋人同士・人狼神の把握情報）が表示される。
7. **自己紹介タイム**：プレイヤー全員でリアルに自己紹介を行う。
8. **初日の夜（0ターン目夜）**：
   * **誰も殺されない（人狼の夜襲なし）**。
   * **占い師のみスキル発動可能**（※初日の夜はサイコキラーを占っても返り討ちは無効）。
   * 他のプレイヤーは説明文を読んで「OK」をタップする。

---

### 【メインループ（朝5分・昼5分・夜5分 × 指定ターン数［デフォルト5ターン］）】

#### 9. 朝のターン開始（制限時間：5分）
* **前夜の追放者・夜襲（犠牲者／復活者）の発表**（※2ターン目以降の冒頭で発表）
  * ※ここで勝敗条件（どちらかの陣営全滅）を満たしていればゲーム終了。
* **本日のタスク（ミニゲーム）と、タスク報酬（メリット）または罰（デメリット）の発表**
  * 毎ターン、タスク1つと、**「メリット（成功報酬）」および「デメリット（失敗時の罰）」の両方を合わせた全ラインナップの中からランダムで1つだけ**が選出される。
    * 「メリット」が選ばれたターン：タスク成功でその報酬を獲得（失敗時は何も起きない）。
    * 「デメリット」が選ばれたターン：タスク失敗でその罰が発生（成功時は罰を回避できる）。
  * **【重複なしルール】**：**1ゲーム（最大5ターン）の中で、同じタスクや同じ報酬（または罰）が2回以上出ることはない**。

#### 10. タスク実行
* 生存しているプレイヤー全員でタスク（ミニゲーム）をこなす（※死亡者は復活の可能性があるため静観）。

#### 11. タスク結果・貢献度の発表
* タスクの成否（報酬獲得 or 罰の発生）を発表する。
* **各プレイヤーの「タスクへの貢献度」もあわせて公開する**。
  * **【ゲーム性の狙い】**：貢献度が可視化されることで、人狼側があからさまなサボり・妨害をするとすぐにバレてしまうため、「バレないようにギリギリで足を引っ張る」という高度な心理戦・攻防を生み出す。

#### 12. 昼のターン：話し合い（制限時間：5分）
* 生存者全員で議論を行う（タスクの貢献度や占い結果などを手がかりに推理する）。

#### 13. 夜のターン：追放投票 ＆ スキル発動（制限時間：5分）
1. **追放者を決める（投票）**
   * 生存者全員で追放したい人に投票する（同票の場合は最多得票者の中からランダムで決定）。
   * ※朝のタスク罰で「追放2人」が発生している場合は、得票上位2名が追放対象となる。
   * 全員の投票が完了した時点でシステム内部で追放者が確定する（※全体への発表は翌朝のステップ9で行う）。
2. **【条件付き】復活者を決める（投票）**
   * 朝のタスク報酬で「脱落者を1人復活できる」を獲得していた場合のみ発生。
   * 通常の追放投票とは別に、脱落者（過去の追放者・夜襲犠牲者全員）の中から復活させたい1人を生存者全員の投票で選ぶ（同票の場合はランダム）。
3. **スキル発動・夜襲ターン（結果は即時表示）**
   * **スマホを見る動作で役職がバレないよう、全員がこのタイミングで画面を確認して「OK」をタップする。**
   * **占い師**：対象を1人選択し、**その場ですぐに占い結果（「人間」or「人狼」）を確認**してOKをタップする（※タスク罰で「占い師スキル無効」の夜は発動不可）。
   * **霊媒師**：スキルを発動し、**直前の投票で確定した追放者の霊媒結果（「人間」or「人狼」）をその場ですぐに確認**してOKをタップする。
   * **騎士・コスプレイヤー・奇跡の医者**：対象を選択し、確認してOKをタップする。
   * **人狼（人狼神・人狼）**：誰を夜襲するか投票で決める（複数人いる場合は多数決、同票の場合は候補からランダム。タスク罰で「夜襲＋1人」の夜は2人襲撃、タスク報酬で「夜襲封じ」の夜は襲撃不可）。
   * **市民（および行動のない役職）**：説明文を読んで「OK」をタップする（※タスク報酬で「全員ナイトスキル」「全員占いスキル」が発生している夜は、対象を選択してスキルを発動できる）。
   * **【スキル無効ルール】**：追放された人、および人狼に夜襲されて死亡した人は、この夜のスキル使用が無効となる（占い師・霊媒師も翌朝死亡して議論に参加できなくなる）。

*(※以降、決着がつくか5ターン目が終了するまで「9. 朝のターン」〜「13. 夜のターン」を繰り返す)*

## 3. 勝利条件・陣営カウント

### カウント方法
* **人狼陣営としてカウントする役職**：人狼神、人狼、狂人、サイコキラー
* **市民陣営としてカウントする役職**：市民、占い師、霊媒師、騎士、恋人、コスプレイヤー、奇跡の医者

### 勝敗判定
1. **途中決着（最大ターン終了前）**
   * **市民陣営の勝利**：人狼陣営が全滅（生存0人）した時点
   * **人狼陣営の勝利**：市民陣営が全滅（生存0人）した時点
2. **指定ターン数（デフォルト5ターン）経過による強制終了時**
   * ルーム作成時に指定された最大ターン数（デフォルト5ターン）終了時点で生存している**「市民陣営の人数」と「人狼陣営の人数」を比較し、人数が多い方の陣営が勝利**となる。
   * **両陣営の生存人数が同数だった場合は「引き分け」**とする。

### 死亡したプレイヤーの扱い
* 「奇跡の医者」またはタスク報酬による復活の可能性があるため、死亡したプレイヤーもゲーム終了まで退出せず静観（待機）する。

## 4. 役職一覧と能力仕様

* **配分ルール**：
  * ルームオーナーが開始前にUI上で役職の配分を設定できる。
  * **市民陣営の能力役職（占い師・霊媒師・騎士・コスプレイヤー・奇跡の医者）は各1人または0人（チェックボックスでON/OFF）**を選択する。
  * **恋人はチェックボックスONで2人（2人1セット）、OFFで0人**となり、市民陣営の残り枠には自動的に「市民」が割り当てられる。

### 【人狼陣営】（10人プレイ時の目安枠数：3）

| 役職名 | 能力・特徴 | 夜の襲撃 | 占い・霊媒判定 |
| :--- | :--- | :---: | :---: |
| **人狼神** | ・最初から**全プレイヤーの役職がすべてわかる**。<br>・人狼と協力して夜に市民を襲撃する。 | あり | 人狼（黒） |
| **人狼** | ・人狼同士（人狼神含む）はお互いがわかる。<br>・協力して夜に市民を襲撃する。 | あり | 人狼（黒） |
| **狂人** | ・人狼の味方をする人間。<br>・特殊能力や襲撃能力は持たないが、占い結果が「人間」と出る。 | なし | 人間（白） |
| **サイコキラー** | ・夜に自分へ関わった（能力や襲撃の対象にした）プレイヤーを、人狼側・市民側問わず**全員返り討ちにして殺害**する（自身は死亡しない）。※初日夜のみ返り討ち無効。<br>　- 占い師に占われた場合 ➔ 占い師が死亡<br>　- 騎士・コスプレイヤーに守られた場合 ➔ 守った騎士・コスプレイヤーが死亡<br>　- 人狼に襲撃された場合 ➔ 襲撃した人狼が死亡（サイコキラーは生存）<br>　- 奇跡の医者に復活させられた場合 ➔ サイコキラーが復活し、奇跡の医者が死亡<br>・通常の人狼からは誰がサイコキラーか分からない（※人狼神からは把握可能）。 | なし | 人間（白） |

### 【市民陣営】（10人プレイ時の目安枠数：7）

| 役職名 | 能力・特徴 | 夜の行動 | 占い・霊媒判定 |
| :--- | :--- | :---: | :---: |
| **市民** | ・特殊能力なし。議論と投票で人狼を推理・追放する。 | 説明文を読んでOK | 人間（白） |
| **占い師** | ・毎夜1人を占い、「人狼」か「人間」かを知る（初日夜も発動可）。 | 毎夜1人占い | 人間（白） |
| **霊媒師** | ・追放された人が「人狼」だったか「人間」だったかを知る。 | 追放者の判定確認 | 人間（白） |
| **騎士** | ・毎夜1人を指定し、人狼の襲撃から守る。 | 毎夜1人護衛 | 人間（白） |
| **恋人** | ・2人で1セットの役職。お互いに市民（恋人）だと最初からわかる。<br>・**片方が死亡すると、もう片方も後追いして死亡する。** | 説明文を読んでOK | 人間（白） |
| **コスプレイヤー** | ・騎士と同じく、毎夜1人を人狼の襲撃から守る（夜襲はしない）。<br>・コスプレをしているため、**占われると「人狼」と判定される**。 | 毎夜1人護衛 | **人狼（黒）** |
| **奇跡の医者** | ・**ゲーム中1回のみ**、死亡したプレイヤー1人を復活させることができる。<br>・人狼側・市民側問わず復活させる。<br>・ただし、**サイコキラーを復活させた場合は、復活させた後に奇跡の医者自身が死亡する**。 | ゲーム中1回蘇生 | 人間（白） |

## 5. 朝のターン「タスク（ミニゲーム）」仕様
* **参加者**：生存している人狼・市民全員（死亡者は静観）
* **抽選仕様**：毎ターンの朝にランダムで選出される。**1ゲーム内で同じタスクや同じ報酬（・罰）は2回出ない**。
* **拡張性**：後から新しいミニゲームや報酬・罰を容易に追加できるプラグイン／モジュール構造で設計する。
* **貢献度の可視化**：タスク終了時に各プレイヤーの貢献度（連打数、入力した回答、ストップした秒数など）を表示し、昼の議論の推理材料とする。

### 初期実装ミニゲーム一覧（全5種）

| No. | ミニゲーム名 | ルール・クリア条件 | 入力・判定の仕様 |
| :---: | :--- | :--- | :--- |
| **1** | **みんなで連打** | 制限時間1分間、生存メンバー全員で画面を連打する。<br>**合計連打数が「生存メンバー数 × 100」以上**になれば成功。 | 各プレイヤーの連打回数を貢献度として集計・表示。 |
| **2** | **気持ちを合わせろクイズ** | 「赤い果物」などの簡単なお題に対し、各自が画面に回答を入力する。<br>**生存者全員の回答が一致**すれば成功。 | 表記揺れを防ぐため、お題に**「ひらがなで答えろ」「漢字で答えろ」**などの入力制限を明記する。 |
| **3** | **かぶっちゃだめよクイズ** | 「果物」などのざっくりとしたお題に対し、各自が画面に回答を入力する。<br>**回答が他の人と1人もかぶらなければ**成功。 | お題に**「ひらがなで答えろ」「漢字で答えろ」**などの入力制限を明記する。 |
| **4** | **みんな答えろクイズ** | 「都道府県」などのお題に対し、順番に回答を入力していく。<br>**制限時間1分以内に全員が（重複せず正しく）回答できれば**成功。 | お題に**「漢字で答えろ」「ひらがなで答えろ」**などの入力制限を明記する。 |
| **5** | **10秒チャレンジ** | タイマーをスタートし、各自が10.0秒だと思ったタイミングでストップする。<br>**プラスマイナス0.5秒以内（9.5秒〜10.5秒）**なら成功（※わざと緩めの判定に設定）。 | 各プレイヤーのストップした秒数（誤差）を貢献度として表示。 |

### タスク報酬（メリット）と罰（デメリット）のラインナップ
毎ターンの朝に、以下の「メリット（5種）」と「デメリット（3種）」の**計8種の中からランダムで1つだけ（1ゲーム内で重複なし）**が選出・発表され、タスク結果に応じてそのターンの昼・夜に効果が適用される。

#### ✨ メリット（タスク成功時の報酬：市民側に有利）
| No. | 報酬名 | 効果詳細 |
| :---: | :--- | :--- |
| **1** | **全員ナイト（騎士）スキル付与** | 今晩1回限り、市民全員がナイト（護衛）スキルを使える。<br>※誰が誰を守るかは共有できず、同じ人を重複して守る場合もある。 |
| **2** | **全員占い師スキル付与** | 今晩1回限り、全員が占い師能力を一度だけ使える。 |
| **3** | **脱落者1名復活投票** | 今晩1回限り、脱落者（追放者・夜襲犠牲者全員含む）の中から1人だけ復活できる。<br>※夜のターンに、追放投票とは別に「復活させる人を選ぶ投票」の手順が追加される（最悪、人狼を復活させてしまう可能性もある）。 |
| **4** | **夜襲封じ** | 今晩1回限り、人狼による夜襲が封じられ、夜襲による犠牲者が0人になる。 |
| **5** | **人狼陣営の生存数公開** | 現在生存している「人狼陣営の残り人数（何人残っているか）」が全員に公開される。 |

#### 💀 デメリット（タスク失敗時の罰：市民側に不利）
| No. | 罰名 | 効果詳細 |
| :---: | :--- | :--- |
| **1** | **夜襲対象＋1人** | 今晩1回限り、人狼の夜襲で襲われる人数が1人増える（計2人襲撃される）。 |
| **2** | **占い師スキル無効** | 今晩1回限り、占い師のスキルが無効（使用不可）になる。 |
| **3** | **追放投票で2人追放** | 今晩1回限り、夜の追放投票で追放される人数が「2人」（得票上位2名）になる。 |
