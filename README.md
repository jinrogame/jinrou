# オリジナル人狼ゲーム (TASK & MYSTERY WEREWOLF)

スマートフォン対応のWeb人狼 ＆ ミニゲーム・パーティーゲームです。
フレームワークやビルド環境不要、HTML / CSS / JavaScript (Vanilla ES Modules) と Google Firebase (Cloud Firestore / Authentication) だけで完全リアルタイムマルチプレイを実現しています。

---

## 🎮 特徴

- **完全ノンスクロール設計 (`100dvh`)**：スマートフォン実機で画面スクロールなしで快適に操作可能。
- **11種類の役職**：
  - 人狼陣営：人狼神、人狼、狂人、サイコキラー
  - 市民陣営：市民、占い師、霊媒師、騎士、恋人、コスプレイヤー、奇跡の医者
- **タスク＆報酬（罰）システム**：
  - 毎朝ミニゲーム（連打、気持ち一致、かぶり禁止、都道府県リレー、10秒チャレンジ）に全員で挑戦
  - 成功すると市民に有利なメリット報酬、失敗するとデメリット罰が発生
  - 個人の貢献度が公開されるため、人狼はバレないように妨害する駆け引きが発生
- **ホスト権威型ステートマシン**：
  - ルームオーナー端末が判定エンジン（ゲームマスター）を兼ねるサーバーレス設計
  - 投票・サイコキラー返り討ち・夜襲・護衛・蘇生・恋人後追いを矛盾なく一括判定
- **顔アイコン自撮り登録**：
  - スマホのインカメラまたは写真選択から自分の顔をアイコンに登録（Canvas軽量圧縮）

## 🚀 ローカル起動方法

静的Webサーバーで `app` ディレクトリを配信するだけで動作します。

```bash
# Node.js の静的サーバーを利用する場合
npx http-server app -p 8080 -c-1

# ブラウザでアクセス
# 通常モード: http://localhost:8080/
# 1台のPCで複数タブから別プレイヤーとしてテストする場合:
# http://localhost:8080/?dev=1
```
